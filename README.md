Broken Crystals Security Assessment

This repository contains a hands-on Web Application Vulnerability Assessment and Penetration Testing (VAPT) project performed on Broken Crystals in a local lab environment using WSL and Docker.

## Tools Used

* WSL (Windows Subsystem for Linux)
* Ubuntu
* Docker
* Burp Suite

## Vulnerabilities Tested

* Brute Force
* Business Logic Abuse
* CORS
* CSRF
* File Upload Vulnerability
* GraphQL Introspection
* ID Enumeration \& Broken Function-Level Authorization (BFLA)
* Insecure Output Handling
* JWT
* OS Command Injection
* SMTP Injection
* SQL Injection
* Server-Side Request Forgery (SSRF)
* Server-Side Template Injection (SSTI)
* Cross-Site Scripting (XSS)

Each folder contains:

* Vulnerability report
* Exploitation process
* Payloads
* Proof of Concept (PoC)
* Screenshots
* Remediation recommendations
